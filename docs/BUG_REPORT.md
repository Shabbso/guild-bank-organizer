# Bug report guide

Please include:

1. Guild Bank Organizer version.
2. WoW client version, build, and interface number.
3. What you clicked and what you expected.
4. Whether the selected tab changed or anyone manually used the bank.
5. Any Lua error and its full stack trace.
6. The operation report from **Advanced → Copy Report**.

Operation reports include the character and realm names so maintainers can
distinguish test environments. Redact those two values before posting if you
prefer not to share them.

If an item appears to be in the wrong location, close and reopen the guild bank
before reporting it. The server can update guild-bank slots after the local UI.
Do not begin moving more items until the cursor is empty and the bank has
settled.
